---

During the first week of my research project, I focused on reading the `PainData.csv` file into Python and organizing the information into structures that could later be used for analysis and machine learning.

One challenge was that the rows in the dataset did not all contain the same number of values. To handle this, I created Python code that could read rows of different lengths without losing data. I separated the participant metadata from the physiological signal measurements and converted the signal values into numeric form.

The metadata included information such as the subject, gender, signal type, and pain condition. The remaining columns contained the physiological signal measurements. I stored the cleaned metadata and signal data separately and saved the processed information in a reusable format.

This step created the foundation for the rest of the project because the dataset can now be loaded efficiently for visualization, statistical analysis, and machine-learning experiments.
